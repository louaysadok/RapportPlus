📱 Pousser Rapport+ sur GitHub — Sans PC (3 min)

Depuis ton téléphone Android, avec Chrome seulement. GitHub va construire l'APK gratuitement.

Étape 0 — Télécharge le projet

Dans ce chat, dans la section Fichiers (à droite), tu vois :

  • rapport_plus_project.zip (78 Ko) — Télécharge-le sur ton téléphone
  • Garde-le dans Téléchargements
💡 Si tu ne vois pas Fichiers : clique sur l'icône dossier en haut de ce chat → rapport_plus_project.zip → Download

Étape 1 — Crée un compte GitHub

1 Ouvre Chrome sur ton téléphone
2 Va sur github.com
3 Clique Sign up → email / password → vérifie email
4 Connecte-toi

Gratuit à vie — pas de carte bancaire.

Étape 2 — Crée le repository

1 Clique + en haut à droite → New repository
2 Nom : rapport-plus
3 Coche Public (obligatoire pour Actions gratuits)
4 Clique Create repository
⚠️ Ne coche pas "Add README" — laisse vide.

Étape 3 — Upload le projet

1 Sur la page vide, clique uploading an existing file (lien bleu)
2 Clique choose your files
3 Va dans Téléchargements → sélectionne rapport_plus_project.zip
4 Attends 100% → clique Commit changes (bouton vert)

💡 Alternative si zip pose problème :
- Décompresse le zip sur ton téléphone (app Files → long press → Extract)
- Sur GitHub, clique Add file → Upload files → sélectionne tous les fichiers décompressés

Étape 4 — Le build se lance tout seul 🤖

1 Clique onglet Actions en haut
2 Tu verras : Build Rapport+ APK 🟡 in progress
3 Attends 8-12 minutes (serveur GitHub compile)
4 Quand c'est vert ✅ → clique dessus

Étape 5 — Télécharge l'APK 📥

1 Scroll en bas → section Artifacts
2 Clique rapport-plus-apks → téléchargement
3 Décompresse → tu as app-debug.apk + app-release.apk
4 Ouvre app-debug.apk → Installer → Autorise "Sources inconnues" si demandé → Ouvre l'app 🎉

Alternative — Lien direct build

Une fois le repo créé, tu peux aussi déclencher le build manuellement :

Actions → Build Rapport+ APK → Run workflow → vert

Le fichier workflow est déjà dans le projet : .github/workflows/build-apk.yml — rien à configurer.
