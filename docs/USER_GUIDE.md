# Guide utilisateur Rapport+

## Premier lancement
1. L'app s'ouvre sur **Paramètres** → Bienvenue !
2. **Google Drive** (optionnel) : Connecter ou "Passer pour l'instant"
3. Renseigner nom, établissement, filière, entreprise (optionnel)
4. "Continuer vers le tableau de bord"

## Au quotidien
- **Dashboard** : progression stage, bouton "Nouvelle entrée"
- **Journal** : Écrire librement ou répondre aux questions guidées. Dicter via 🎤 (vérifier transcription !). Joindre photos/vidéos. L'IA classe automatiquement Réalisé/Observé/etc.
- **Rappel 18h** configuré → modifiable dans Paramètres

## Rapport
- Se construit automatiquement à partir du journal
- Chapitres colorés : vert=approuvé, bleu=généré IA, orange=à compléter
- Répondre aux questions "Infos manquantes" pour améliorer
- Glisser pour réordonner, masquer sections inutiles, ajouter chapitres custom
- **Aperçu** puis **Exporter PDF/DOCX**

## Soutenance
- Questions générées sur vos vraies activités
- Simulation : répondre → note + feedback → exemple amélioré
- Flashcards à réviser
